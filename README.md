# Aman Bhardwaj — Next.js Portfolio

A responsive developer portfolio built with **Next.js 14 App Router**, React, TypeScript, and custom CSS. No UI library is required.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. Your email, GitHub, and LinkedIn links are already configured.
2. The custom AB favicon is included at `app/icon.png` and configured in `app/layout.tsx`.
3. Confirm the e-commerce project URL is live and publicly accessible.
4. Update project descriptions or technology tags to match the exact implementation.

## Deploy

Push this folder to a GitHub repository and import it into Vercel. Vercel will detect Next.js automatically.
